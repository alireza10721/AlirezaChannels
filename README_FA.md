# Alireza Channels

سازنده: alireza10721@gmail.com

## وضعیت این نسخه
این پروژه یک پوسته اولیه اندروید است:
- در اولین اجرا رمز عددی حداقل ۴ رقمی می‌سازد و برای دفعات بعد همان رمز را می‌خواهد.
- لینک‌های HTTPS کانال را می‌توان اضافه و باز کرد.
- صفحه تنظیمات سرور فعلاً توضیحی است؛ هنوز تونل VPN درون‌برنامه‌ای پیاده‌سازی نشده است.

**مهم:** چون هنوز سرور و پروتکل مشخصی ندارید، این APK فیلتر را دور نمی‌زند و بدون سرور VPN کارکرد VPN ندارد. برنامه نمی‌تواند صرفاً با کد نویسی به «سرور آزاد» متصل شود؛ باید سرور مجاز و اطلاعات اتصال واقعی تهیه شود. رمز برنامه نیز در این نسخه برای قفل ساده محلی است و برای حفاظت امنیتی قوی باید در نسخه نهایی با Android Keystore و هش امن جایگزین شود.

## ساخت APK با GitHub
1. در GitHub یک مخزن جدید بسازید.
2. فایل ZIP را از حالت فشرده خارج کنید.
3. همه فایل‌ها و پوشه‌ها (از جمله `.github`) را در مخزن آپلود و commit کنید.
4. وارد تب **Actions** شوید.
5. گردش‌کار **Build Android APK** را اجرا کنید یا پس از push منتظر بمانید.
6. در پایان، از بخش **Artifacts** فایل `Alireza-Channels-debug-apk` را دانلود کنید.
7. APK داخل ZIP دانلودشده قرار دارد.

## نیازمندی نسخه VPN واقعی
برای اضافه کردن اتصال واقعی باید یکی از این موارد فراهم شود:
- فایل پیکربندی WireGuard معتبر، یا
- لینک/فایل پیکربندی VLESS/VMess/Trojan و انتخاب هسته سازگار.

پس از مشخص شدن پروتکل و داشتن سرور، می‌توان ماژول VPN را به پروژه اضافه کرد. دسترسی VPN در اندروید نیازمند تأیید اولیه کاربر از پنجره سیستمی Android است.
